## 十二、v8 动效层（全站统一）+ 两个真 Bug

### 12.1 Bug①：浅色主题「选中标签变黑块」
**根因**：浅色主题有一条为"加深角色名字"而写的规则把选中标签也匹配进去了：
```css
html[data-theme="light"] .acard .au, .msg b, .dchip.on, ... { filter: brightness(.42) saturate(1.9) }
```
浅色品牌淡底 `rgb(230,248,249)` 被压暗 58% → 变成近黑色块。
**修复**：从该规则里移除 `.dchip.on`（选中态文字本来就用 `--tx` 深色，对比度已达标）。
**验证**：浅色下选中「全部」= `bg rgb(230,248,249) / 边框 #00B8C4 / 文字 #1D2129 / filter:none`；三主题扫描无其它深底选中态。

### 12.2 Bug②：发完消息要刷新才显示（自己发的和他回的）
**两层根因**：
1. **引擎**：`events.jsonl` 跨多次重启持续追加，但 `seq` 每次都从 0 重开 → 同一 `(runId, seq)` 重复出现（实测文件里 seq 最大 68 在中间、当前计数器才 60）。
2. **前端**：去重逻辑用 `seq <= lastApplied` 比大小 → 运行结束后产生的聊天事件 seq 更小，被当成"已见过"直接丢弃；页面只有刷新时通过 `subscribe()` 的全量历史重放才能看到。

**修复**：
- `bus.js` 新增 `seedSeq(file)`：`setRun` / `rehydrate` 都从**事件文件的最大 seq** 续号 → `(runId, seq)` 永久唯一。
- `app.js` / `chat.html` 改用**记账集合** `seenKeys`（键 `runId#seq#ts`）去重，不再比大小；启动时把 state 历史登记进去，避免 SSE 重放重复渲染。
**验证**（不刷新）：协作台发消息 **1.2 秒内**出现、12 秒内收到回复；对话台同样 30→31→32；两个页面零 JS 报错；消息顺序按时间正确。

### 12.3 动效层（index.html + chat.html）
统一节奏、统一缓动（`cubic-bezier(.22,.9,.3,1)`），并支持 `prefers-reduced-motion`：
- **入场**：面板淡入、卡片/表格行/路由行/标签错峰上浮（40ms 递增）
- **hover 抬升**：`.dcard/.acard/.pvcard` 上浮 2px + 阴影；`.hrow/.fororow` 右移 2px；浅色主题单独用更淡的阴影避免脏感
- **按压**：按钮/标签 `translateY(1px) scale(.985)`
- **光泽**：主按钮 hover 有一道白色斜光扫过（`::after` + `ptSheen`）
- **状态**：健康圆点 3.4s 呼吸；选中标签圆点 / 运行中节点 / 卡片 2s 脉冲扩散；节点状态切换时头像轻弹一下（`st()` 加 `ping`）
- **指标**：数字变化时闪一下品牌底色（`stats()` 用 `bump()` 改写）
- **容灾**：切换到备用模型时双向箭头出现流动高亮
- **弹窗/toast**：`ptPop` 弹出、toast 上浮滑入
- **消息**：每条消息入场动画 + hover 品牌淡底
- 实测 index 常驻动效 69 个、chat 47 个，双主题均无报错
